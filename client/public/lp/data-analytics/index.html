1Phase 1Data Analytics Foundations & Business IntelligenceEvery data analyst needs a rock-solid grip on what analytics is, where it fits in business decisions, and the data all around them.
Analytics Foundations · Business IntelligenceAnalyticsBIData SourcesKPI
  • Introduction to Data Analytics, its global scope & role of a Data Analyst
  • Data Analytics vs Business Analytics — key differences
  • The Data Analytics method — from question to insight
  • What is BI and why it matters; popular BI tools & techniques
  • Identifying & evaluating reliable data sources
  • Types of data: structured, unstructured, qualitative & quantitative
What you'll be able to do after Phase 1

By the end of this phase, every student can explain the full data analytics lifecycle, choose the right BI approach for a business problem, and classify any dataset before analysis begins.

Where this shows up on the job

Every time a business asks “why did sales drop last quarter?”, this is the phase that teaches you to pick the right data source, the right BI tool, and the right metric before opening any tool.

2Phase 2Python Programming FundamentalsA strong Python foundation that powers every later phase — from cleaning data to building GenAI-assisted workflows.
Python Basics · Working With DataPythonJupyterGoogle ColabSQLite
  • Installing & working with Jupyter Notebook and Google Colab
  • Python operators, data types & built-in functions
  • Lists, slicing, tuples, dictionaries, sets, def & return statements
  • Advanced Python functions & intro to SQLite operations
  • Date-time manipulation & data cleaning techniques
  • Writing clean, reusable functions for analytics workflows
What you'll be able to do after Phase 2

By the end of this phase, every student can write clean, working Python code to load, clean and reshape any dataset — ready to feed into analysis and visualization tools.

Where this shows up on the job

Analysts spend a large share of their week cleaning and reshaping data before any dashboard gets built — the Python fundamentals from this phase are what make that process fast instead of painful.

3Phase 3Python for Data Analysis & VisualizationMaster the core data-science libraries used daily by analysts to explore, visualise and present real-world datasets.
Core Libraries · Applied VisualizationNumPyPandasSeabornStreamlit
  • NumPy for fast numerical computing & array operations
  • Pandas — Series, DataFrames & real-world data wrangling
  • Matplotlib, Seaborn & Plotly for data visualization
  • Bar plots, quiver & stream plots for advanced charting
  • Visualising distributions & relationships in real datasets
  • Building interactive mini-apps with Streamlit
What you'll be able to do after Phase 3

By the end of this phase, every student can independently clean, explore and visualise any dataset in Python, and package findings into a shareable Streamlit app.

Where this shows up on the job

A quick Pandas-and-Seaborn exploration is usually the first thing an analyst does with any new dataset — before a single dashboard or report gets built.

4Phase 4Statistics, Probability & SQL for AnalyticsDevelop the statistical thinking and SQL fluency every data analyst needs to query databases and validate insights.
Statistics & EDA · SQL for AnalystsSQLMySQLJoinsWindow Functions
  • Statistics & Probability fundamentals for analytics
  • Exploratory Data Analysis (EDA) techniques & workflow
  • Data modelling & normalization principles
  • SQL fundamentals, MySQL interface, DDL/DML/DQL/TCL/DCL
  • Joins, constraints, indexes, views & subqueries
  • Aggregate, string, temporal & window functions
What you'll be able to do after Phase 4

By the end of this phase, every student can write production-grade SQL queries confidently and apply statistical reasoning to validate every insight they report.

Where this shows up on the job

SQL is the single most-listed skill on Indian data analyst job postings. This phase ensures you can write a multi-table join or a window-function query live, in any interview, without hesitation.

5Phase 5Power BI: Visualization & Business IntelligenceMaster Microsoft Power BI end-to-end — from connecting raw data to publishing live, scheduled dashboards.
Building Dashboards · Reports & PublishingPower BIPower QueryDAXDashboards
  • Introduction to Power BI and the BI workflow
  • Data modeling, relationships & Power Query Editor
  • Data visualization principles — choosing the right chart
  • Building dashboards with animated & custom visuals
  • Creating multi-page interactive reports
  • Publishing, sharing & scheduling automatic refreshes
What you'll be able to do after Phase 5

By the end of this phase, every student can independently build and publish a complete, auto-refreshing Power BI dashboard — the exact deliverable BI Analyst roles expect from day one.

Where this shows up on the job

This is the exact workflow a working BI Analyst follows every week — connect a live data source, model the relationships, build visuals, and publish a report that refreshes itself every morning.

6Phase 6Advanced Excel & TableauGo beyond basic spreadsheets — master advanced Excel for reporting and Tableau for enterprise-grade analytics.
Advanced Excel · TableauExcelVBATableauPivot Tables
  • Worksheets, workbook management & business formulas
  • Data cleaning, validation & charts directly in Excel
  • Macros, VBA automation & security features
  • Introduction to Tableau and its interface
  • Tableau end-to-end — from data source to dashboard
  • Using SQL as a data source & executive dashboard design
What you'll be able to do after Phase 6

By the end of this phase, every student is fluent across all three major BI tools in the industry (Excel, Power BI and Tableau) — ready for whichever stack an employer runs.

Where this shows up on the job

Even companies that run on Power BI often still receive data as Excel files from vendors and partners — being equally fluent in Excel and Tableau means you're never blocked waiting for someone else to reformat a file.

7Phase 7Generative AI for Data AnalyticsLearn how Generative AI is transforming analytics work — from automating reports to accelerating insight generation.
GenAI Foundations · Applied GenAIGenAILLMPrompt EngineeringNLP
  • Introduction to Generative AI & large language models

  • Advanced topics in Generative AI with NLP
  • Prompt Engineering fundamentals & best practices
  • Using AI tools to summarise, explain & automate reporting
  • Responsible & ethical use of AI in business analytics
What you'll be able to do after Phase 7

By the end of this phase, every student can combine traditional analytics with Generative AI — drafting insight summaries and using prompt engineering for faster, more accurate analysis.

Where this shows up on the job

Instead of spending an hour writing a dashboard summary by hand, an AI-augmented analyst drafts the first version with a well-engineered prompt in minutes — then spends the saved time on deeper analysis.
